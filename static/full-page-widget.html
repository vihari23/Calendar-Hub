Vihari Calendar Hub
Full-Page Widget

Up to 12 upcoming events, chosen calendar colors, independent widget views, and custom ICS subscriptions. Your work and personal Apple calendars remain untouched.

1. Install the Scripting app

Get Scripting for iPhone. Your existing Scriptable medium/large widget is separate; this full-page version specifically uses Scripting's iOS 27 portrait widget.

2. Install without unzipping

Use the one-tap remote importer. It asks Scripting to import the GitHub project folder directly, so you don't have to select a downloaded ZIP.

Import directly into Scripting

Open this page in Safari on your iPhone. If prompted, allow Safari to open Scripting, and approve the project import.

Alternative: use an import URL inside Scripting

Choose Scripting's Import Scripts / Import from URL option (wording varies), then paste this source:

https://github.com/vihari23/Calendar-Hub/tree/main/scripting

Alternative: install from Files

Download the .scripting file, which iOS recognizes as Scripting's exported script format; open it from Files and choose Scripting. This is preferable to selecting a regular ZIP using the Files importer.

Download .scripting file

The ZIP archive remains available for manual inspection, but it is not the recommended iPhone import method.

3. Configure feeds, colors and widget views

Run Vihari Calendar Hub Full Page inside Scripting. Add an ICS subscription URL and color under Add your own ICS feed. Under Widget view — select calendars, choose which calendars appear for each named view.

Built-in view parameters: all, culture, entertainment, home. Custom views use their own identifiers. Private ICS URLs stay in Scripting's local App Group, not your public GitHub repository.

4. Test on the iPhone

  1. Run Preview XL portrait widget inside the script.
  2. Choose the Scripting extra-large portrait widget on your iPhone Home Screen.
  3. Long-press → Edit Widget → select your new project → set Parameter to a view ID.
  4. Confirm layout, colors, selected calendars, and refresh on your device.

Important: Home Screen widgets cannot scroll internally. Tap the Hub link to open the scrollable dashboard. Desktop simulation is not a substitute for a physical iPhone preview.

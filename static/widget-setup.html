1. Install Scriptable

Get Scriptable for iPhone. A native widget requires an iOS widget host; your GitHub Pages web app cannot install a widget by itself.

2. Copy the widget script

Tap below in Safari. Then open Scriptable, press ＋ to create a script named Calendar Hub Widget and paste the copied code.

Long-press and select all if automatic copying is unavailable.

3. Configure your calendars and colors

Run your new script once in the Scriptable app, then open Manage calendars + colors. Your three public feeds are preloaded.

  1. Tap ＋ Add ICS calendar to add a new HTTPS or webcal subscription address.
  2. Choose a calendar name and one of nine colors (or a custom six-digit hex color).
  3. Tap a calendar later to rename it, change the color, test the feed, or delete it.

Custom ICS URLs and selected colors stay in Scriptable's local storage on your iPhone. They are not added to public GitHub or the Calendar Hub website. Some complex recurrence rules may not render perfectly; compare those feeds with Apple Calendar.

4. Choose calendars separately for each widget

In Scriptable run Manage widget views and create a named view, such as "Family", "OTT only", or "Festivals + Home". Tap feed names to toggle them.

Each view has its own stable ID. The widget does not control which calendars appear in Apple Calendar.

5. Add each widget to your Home Screen

  1. Long-press your iPhone Home Screen, tap ＋, and search for Scriptable.
  2. Choose the Medium or Large widget.
  3. Long-press the widget and choose Edit Widget.
  4. Select Script → Calendar Hub Widget.
  5. For Parameter enter a view ID such as all or home.
  6. Add another Scriptable widget and use a different Parameter for another calendar combination.

Tap your widget to open a complete, scrollable agenda inside Scriptable. iOS Home Screen widgets themselves cannot scroll their contents.
